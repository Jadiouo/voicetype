# 抽樣校對

在圖示的「待校對」勾選抽樣。新安裝預設關閉；開啟後，8–61秒的主動聽寫以約三分之一機率抽樣，每個本機日曆日最多5段。只從本daemon取得錄音，沒有背景另開麥克風，也不讀別的應用程式內容。

選一段按「重聽這段」，正確就按「這句正確」，有錯則修改完整句子。「記錄修正」保存人工文字；若顯示的詞對合理，按「記錄並加入詞庫」，日後直接套用。多處改寫不會自動變成全域規則。已確認的其他句子仍使用該原詞時，要求更完整的片語。詞庫頁有未儲存編輯時先儲存，避免兩處更新互相覆蓋。

這是在累積人工確認的詞庫，沒有訓練模型。僅確認正確不會讓模型自動變準。圖示每60秒更新待校對數，不定時彈出視窗；開啟頁面或按重新整理可更新清單。

## 保存範圍

- `~/.config/voicetype/review.json`控制開關與每日上限，支援XDG路徑。GUI上限為5，daemon可讀1–5；無效設定停用抽樣。
- `~/.local/share/voicetype/review/`保存16kHz單聲道PCM WAV、原ASR文字、當時輸出、人工校對和狀態。目錄0700、檔案0600，不上傳。
- 保留VAD修剪前的完整音訊，包含停頓。辨識失敗、空結果或過期session不保存。
- 有界背景佇列滿或磁碟忙碌時略過。成功進入IPC結果佇列後才提交背景寫檔；這不是桌面插字成功的回執，且選中錄音仍有一次記憶體複製成本。
- 待校對與已校對資料都在建立7天後清理，最多35段。執行中約每60秒清理，關機期間下次啟動清理。手動刪除不重置每日配額。
- 明確加入的詞庫規則獨立保存，刪除樣本或到期清理不撤銷規則。

關閉抽樣只停止新增，原資料仍可重聽、刪除或到期清理。程式、圖示及資料是分開的；更新前可備份daemon與GUI launcher，回退程式應保留詞庫和校對資料。更新daemon前先結束聽寫並等warm音訊串流關閉。

## 驗證

Rust測試涵蓋音訊順序／停頓、配額跨日、取消、過期、忙碌鎖／佇列、7天清理與背景開關；Python測試涵蓋人工確認、词對提升、衝突及資料邊界。這些測試不開麥克風。真人辨識品質與完整快捷鍵到插字延遲需另行量測。
